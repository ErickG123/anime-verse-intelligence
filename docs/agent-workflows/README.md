# Agent Workflows — AnimeVerse Intelligence

Esta pasta centraliza os prompts históricos e checklists de execução utilizados para construir o projeto em ciclos SDD (`PROMPT-00` a `PROMPT-20`).

- [master-prompt.md](master-prompt.md): protocolo de orquestração SDD conservadora.
- [execution-checklist.md](execution-checklist.md): checklist sequencial das fases 00–20.
- [references.md](references.md): referências técnicas oficiais verificadas.
- `prompts/`: textos originais das fases 00–20 mantidos para rastreabilidade histórica.

As regras ativas do agente residem exclusivamente em `AGENTS.md`, `GEMINI.md` e `.agents/rules/`.
