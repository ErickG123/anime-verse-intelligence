# Política de Curadoria e Evidências — AdaptationLab

**Versão:** `1.0`  
**Data:** 2026-11-23

1. Somente mapeamentos revisados com `evidenceRef` autorizado podem ser publicados; nunca afirmar correspondência automática linear (`capítulos / episódios`) como fato.
2. Nunca incorporar scans, páginas de mangá, frames de anime ou legendas protegidas por direitos autorais.
3. `UNKNOWN` representa ausência de mapeamento verificado — jamais deve ser apresentado como `OMITTED` (conteúdo cortado).
4. Obras anime-originais exibem estado explícito `ANIME_ORIGINAL` sem forçar referência a mangá inexistente.
