# Glossário de Domínio — AnimeVerse Intelligence

**Status:** Aprovado (Fase 01)

| Termo                                         | Definição                                                                                                                                                                                                                                                      |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Anime**                                     | Obra audiovisual catalogada com identificador interno imutável (`UUID`), título principal, tipo (`TV`, `MOVIE`, `OVA`, `ONA`, `SPECIAL`, `UNKNOWN`), status e metadados opcionais.                                                                             |
| **Alias / Sinônimo**                          | Título alternativo associado a um `Anime` (`synonyms` do dataset), usado para exibição e busca.                                                                                                                                                                |
| **External Reference (`external_reference`)** | Vínculo entre um `Anime` interno e um provedor externo (ex.: `myanimelist`, `anilist`, `anidb`, `kitsu`, `livechart`, `anime-planet`, `notify-moe`, `anisearch`, `simkl`), composto por URL normalizada, nome do provedor e ID extraído quando determinístico. |
| **Company (`company`)**                       | Organização envolvida na produção de um anime, vinculada via `anime_company` com papel explícito (`STUDIO` ou `PRODUCER`).                                                                                                                                     |
| **Tag (`tag`)**                               | Rótulo temático ou descritivo associado a um anime, normalizado (trim/lowercase para chave de unicidade).                                                                                                                                                      |
| **Anime Relationship (`anime_relationship`)** | Relação entre dois animes internos originada de `relatedAnime`. Sem evidência externa específica, o tipo é obrigatoriamente `UNSPECIFIED`.                                                                                                                     |
| **Data Source (`data_source`)**               | Registro governado de uma fonte de dados (ex.: `anime-offline-database`), incluindo licença, atribuição obrigatória, permissão de armazenamento e estado (`ACTIVE` / `INACTIVE`).                                                                              |
| **Source Snapshot (`source_snapshot`)**       | Versão específica de um arquivo/release importado (ex.: data `lastUpdate`, hash SHA-256, contagem de registros e metadados da linha 1 do JSONL).                                                                                                               |
| **Ingestion Run (`ingestion_run`)**           | Execução auditável do pipeline de importação para um `source_snapshot`, com timestamps, status (`RUNNING`, `COMPLETED`, `FAILED`, `PARTIAL`), contadores e erros.                                                                                              |
| **Source Evidence (`source_evidence`)**       | Registro de rastreabilidade que vincula uma entidade ou fato persistido à fonte e snapshot que o originaram.                                                                                                                                                   |
| **Ingestion Conflict (`ingestion_conflict`)** | Divergência detectada durante a ingestão (ex.: mesmo anime referenciado com atributos conflitantes ou ambiguidade de matching) registrada para revisão sem sobrescrita silenciosa.                                                                             |
| **StudioGraph**                               | Módulo de exploração da rede entre empresas (estúdios/produtoras) e obras. No MVP cobre empresas↔animes; créditos individuais de staff são pós-MVP.                                                                                                            |
| **LoreGraph**                                 | Módulo pós-MVP dedicado a arcos, personagens, eventos e evidências narrativas (inativo/vazio no MVP).                                                                                                                                                          |
| **AdaptationLab**                             | Módulo pós-MVP dedicado à correspondência revisada entre mangá e anime (inativo/vazio no MVP).                                                                                                                                                                 |
| **Problem Details (RFC 7807 / RFC 9457)**     | Formato JSON padronizado de respostas de erro HTTP (`type`, `title`, `status`, `detail`, `instance`, `requestId`, `code`).                                                                                                                                     |
